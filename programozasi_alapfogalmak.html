1. Változó (variable)

Egy elnevezett tárolóhely a memóriában, amiben adatot tárolunk. A változónak van neve, típusa (bizonyos nyelveknél) és értéke, amit menet közben módosíthatunk.
C# – statikusan típusos
int kor = 25;
string nev = "Anna";
kor = 26; // az érték módosítható
JavaScript – dinamikusan típusos
let kor = 25;
let nev = "Anna";
kor = 26; // az érték módosítható

2. Konstans (constant)

Olyan érték, amit egyszer adunk meg, és utána nem lehet megváltoztatni. Akkor használjuk, ha biztosan tudjuk, hogy az érték nem fog változni (pl. PI értéke).
C#
const double PI = 3.14159;
JavaScript
const PI = 3.14159;

3. Adattípusok (data types)

Meghatározzák, milyen fajta adatot tárolhat egy változó: szám, szöveg, logikai érték stb.
TípusJelentésC#JavaScript
Egész számintint x = 5;let x = 5;
Lebegőpontos számtizedes törtdouble y = 3.14;let y = 3.14;
Szövegkaraktersorozatstring s = "Szia";let s = "Szia";
Logikaiigaz/hamisbool b = true;let b = true;
Tömbelemek sorozataint[] t = {1,2,3};let t = [1,2,3];
JavaScriptben nincs kötelező típusmegadás (dinamikus típusosság), C#-ban viszont a fordító ellenőrzi a típusokat (statikus típusosság).

4. Operátorok (operators)

Jelek/szimbólumok, amelyekkel műveleteket végzünk értékeken: számolás, összehasonlítás, logikai kombinálás.
Aritmetikai: + - * / %  |  Összehasonlító: == != > < >= <=  |  Logikai: && || !
C#
int a = 10, b = 3;
int osszeg = a + b;      // 13
bool nagyobb = a > b;    // true
bool esNincs = (a > 5) && (b < 5); // true
JavaScript
let a = 10, b = 3;
let osszeg = a + b;       // 13
let nagyobb = a > b;      // true
let esNincs = (a > 5) && (b < 5); // true
JavaScriptben van == (laza egyenlőség, típuskonverziót végez) és === (szigorú egyenlőség, típust is vizsgálja). Célszerű mindig ===-t használni.

5. Feltételes elágazás (if / else, switch)

Lehetővé teszi, hogy a program bizonyos feltételek alapján más-más kódrészletet hajtson végre.
C#
int eletkor = 17;
if (eletkor >= 18)
{
    Console.WriteLine("Nagykorú");
}
else
{
    Console.WriteLine("Kiskorú");
}
JavaScript
let eletkor = 17;
if (eletkor >= 18) {
    console.log("Nagykorú");
} else {
    console.log("Kiskorú");
}
switch – C#
switch (nap)
{
    case 1: Console.WriteLine("Hétfő"); break;
    case 2: Console.WriteLine("Kedd"); break;
    default: Console.WriteLine("Ismeretlen nap"); break;
}

6. Ciklusok (loops)

Kódrészlet ismételt végrehajtása, amíg egy feltétel teljesül, vagy adott számú alkalommal.
for – C#
for (int i = 0; i < 5; i++)
{
    Console.WriteLine(i);
}
for – JavaScript
for (let i = 0; i < 5; i++) {
    console.log(i);
}
while – C#
int i = 0;
while (i < 5)
{
    Console.WriteLine(i);
    i++;
}
while – JavaScript
let i = 0;
while (i < 5) {
    console.log(i);
    i++;
}

7. Tömb (array)

Egyforma típusú (C#-ban kötelezően) elemek rendezett, indexelt gyűjteménye.
C#
int[] szamok = { 1, 2, 3, 4 };
Console.WriteLine(szamok[0]); // 1
JavaScript
let szamok = [1, 2, 3, 4];
console.log(szamok[0]); // 1

8. Függvény / metódus (function / method)

Egy elnevezett, újrafelhasználható kódblokk, amely bemenetet (paramétereket) fogadhat, és visszaadhat egy eredményt. Osztályon belül ezt metódusnak nevezzük.
C#
int Osszead(int a, int b)
{
    return a + b;
}

int eredmeny = Osszead(3, 4); // 7
JavaScript
function osszead(a, b) {
    return a + b;
}

let eredmeny = osszead(3, 4); // 7

// arrow function formában
const osszead2 = (a, b) => a + b;

9. String kezelés (szövegek)

A szöveges adatok (stringek) kezelése: összefűzés, hossz lekérdezés, keresés benne.
C#
string nev = "Anna";
string koszones = "Szia, " + nev + "!";
int hossz = nev.Length; // 4
JavaScript
let nev = "Anna";
let koszones = `Szia, ${nev}!`; // template string
let hossz = nev.length; // 4

10. Kivételkezelés (try / catch / exception)

Lehetővé teszi, hogy a program futása közben fellépő hibákat (kivételeket) elkapjuk és lekezeljük, ahelyett hogy a program leállna.
C#
try
{
    int x = 10 / 0;
}
catch (DivideByZeroException e)
{
    Console.WriteLine("Hiba: " + e.Message);
}
JavaScript
try {
    let x = valamiAmiHibatDob();
} catch (e) {
    console.log("Hiba: " + e.message);
}

11. Objektum (object)

Egy adatszerkezet, amely tulajdonságokat (adatokat) és esetleg viselkedést (metódusokat) fog össze. JavaScriptben objektumot típusdefiníció nélkül is létre lehet hozni; C#-ban jellemzően egy osztály "példánya".
JavaScript – objektum literál
let szemely = {
    nev: "Anna",
    kor: 25,
    koszon: function() {
        console.log("Szia, " + this.nev + " vagyok!");
    }
};
szemely.koszon();
C#-ban az objektum mindig egy osztályból jön létre (lásd lentebb, 12. pont).

12. Osztály (class)

Egy "sablon" vagy "terv", amely leírja, milyen tulajdonságai (mezők/property-k) és viselkedése (metódusai) lesznek az abból létrehozott objektumoknak (példányoknak).
C#
class Szemely
{
    public string Nev;
    public int Kor;

    public void Koszon()
    {
        Console.WriteLine("Szia, " + Nev + " vagyok!");
    }
}

// Példányosítás
Szemely anna = new Szemely();
anna.Nev = "Anna";
anna.Kor = 25;
anna.Koszon();
JavaScript (ES6 class)
class Szemely {
    constructor(nev, kor) {
        this.nev = nev;
        this.kor = kor;
    }

    koszon() {
        console.log("Szia, " + this.nev + " vagyok!");
    }
}

let anna = new Szemely("Anna", 25);
anna.koszon();

13. Konstruktor (constructor)

Egy speciális metódus, amely az objektum létrehozásakor (new kulcsszóval) automatikusan lefut, és jellemzően a kezdeti értékek beállítására szolgál.
C#
class Szemely
{
    public string Nev;

    // konstruktor
    public Szemely(string nev)
    {
        Nev = nev;
    }
}

Szemely anna = new Szemely("Anna");
JavaScriptben lásd a 12. pontban a constructor(...) metódust.

14. OOP – Objektumorientált programozás alapelvei

Az OOP négy fő alappillére: egységbezárás, öröklődés, polimorfizmus, absztrakció.

a) Egységbezárás / Beágyazás (Encapsulation)

Az adatok (mezők) és a rájuk vonatkozó műveletek (metódusok) egy egységbe (osztályba) zárása, és a belső adatok hozzáférésének korlátozása (private, public).
C#
class BankSzamla
{
    private double egyenleg;

    public void Befizetes(double osszeg)
    {
        egyenleg += osszeg;
    }

    public double LekerdezEgyenleg()
    {
        return egyenleg;
    }
}
JavaScript (privát mező, ES2022+)
class BankSzamla {
    #egyenleg = 0;

    befizetes(osszeg) {
        this.#egyenleg += osszeg;
    }

    lekerdezEgyenleg() {
        return this.#egyenleg;
    }
}

b) Öröklődés (Inheritance)

Egy osztály (leszármazott) átveheti egy másik osztály (szülő) tulajdonságait és metódusait, és bővítheti vagy felülírhatja azokat.
C# – öröklődés a ":" jellel
class Allat
{
    public void EszikVeg()
    {
        Console.WriteLine("Az állat eszik.");
    }
}

class Kutya : Allat
{
    public void Ugat()
    {
        Console.WriteLine("Vau vau!");
    }
}

Kutya bodri = new Kutya();
bodri.EszikVeg();
bodri.Ugat();
JavaScript – "extends" kulcsszó
class Allat {
    eszik() {
        console.log("Az állat eszik.");
    }
}

class Kutya extends Allat {
    ugat() {
        console.log("Vau vau!");
    }
}

let bodri = new Kutya();
bodri.eszik();
bodri.ugat();

c) Polimorfizmus (Polymorphism)

Különböző osztályok ugyanazt a metódusnevet másképp valósíthatják meg – a program futás közben eldönti, melyik változatot hívja.
C# – virtual / override
class Allat
{
    public virtual void HangotAd()
    {
        Console.WriteLine("Az állat hangot ad.");
    }
}

class Kutya : Allat
{
    public override void HangotAd()
    {
        Console.WriteLine("Vau!");
    }
}

class Macska : Allat
{
    public override void HangotAd()
    {
        Console.WriteLine("Miáú!");
    }
}
JavaScript
class Allat {
    hangotAd() {
        console.log("Az állat hangot ad.");
    }
}

class Kutya extends Allat {
    hangotAd() {
        console.log("Vau!");
    }
}

class Macska extends Allat {
    hangotAd() {
        console.log("Miáú!");
    }
}

d) Absztrakció (Abstraction)

A lényegtelen részletek elrejtése, és csak a lényeges, "kifelé mutatott" viselkedés megjelenítése. Gyakran absztrakt osztályokkal vagy interfészekkel valósítjuk meg.
C# – abstract osztály
abstract class Alakzat
{
    public abstract double Terulet();
}

class Kor : Alakzat
{
    public double Sugar;
    public override double Terulet()
    {
        return Math.PI * Sugar * Sugar;
    }
}
JavaScript – hibadobással szimulálva
class Alakzat {
    terulet() {
        throw new Error("A terulet() metódust felül kell írni!");
    }
}

class Kor extends Alakzat {
    constructor(sugar) {
        super();
        this.sugar = sugar;
    }
    terulet() {
        return Math.PI * this.sugar * this.sugar;
    }
}
JavaScriptben nincs beépített abstract kulcsszó, ezért a hasonló hatást hibadobással szimuláljuk a szülő metódusban.

15. Interfész (interface)

Egy "szerződés", amely megmondja, milyen metódusokat kell megvalósítania egy osztálynak, de az implementációt nem tartalmazza. C#-ban ez nyelvi elem, JavaScriptben nincs beépítve, de a koncepció hasonló mintákkal ("duck typing") kiváltható.
C#
interface IJarmu
{
    void Indit();
}

class Auto : IJarmu
{
    public void Indit()
    {
        Console.WriteLine("Az autó elindult.");
    }
}

16. Statikus tagok (static)

Olyan mező vagy metódus, amely nem egy konkrét példányhoz, hanem magához az osztályhoz tartozik – nem kell hozzá objektumot létrehozni.
C#
class Matek
{
    public static int Negyzet(int x)
    {
        return x * x;
    }
}

int eredmeny = Matek.Negyzet(5); // nincs "new Matek()"
JavaScript
class Matek {
    static negyzet(x) {
        return x * x;
    }
}

let eredmeny = Matek.negyzet(5); // nincs "new Matek()"
